# SmartDine

SmartDine is a smart restaurant management and food ordering system designed to simplify dining experiences through digital technology.

## Features
- Digital Menu Management
- Online Food Ordering
- Table Reservation
- Order Tracking
- Secure Payment Integration

## Tech Stack
### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Purpose
The objective of SmartDine is to reduce manual restaurant operations and provide a seamless digital dining experience.
